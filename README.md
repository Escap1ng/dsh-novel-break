# dsh-novel-break：思维链间隙读小说插件

## 目标

在 DeepSeek Harness（dsh）的 Web 界面中，把模型思维链按块切分，在块与块之间插入小说段落——等 Agent 干活时顺便追更。小说支持导入本地 txt 文件。

## 核心原则

**纯显示层插件**：只改思维链的展示方式，小说内容不进入模型上下文，不影响任务执行、不额外消耗 token。（实现模式参考社区插件 dsh-think-translate）

## 功能设计

1. **txt 导入**：配置 txt 文件路径，自动识别 UTF-8/GBK 编码；按“第X章/第X节”切章，章内按固定字数分块（默认 300–500 字，可调）。
2. **分块插入**：监听思维链流式输出，在自然块边界（段落结束、工具调用间隙）插入小说卡片；每 N 个思维块插一次（可配），思维链很短时不插。
3. **卡片交互**：小说渲染为可折叠卡片，样式与思维链区分；支持“下一章 / 跳过 / 暂停插入”。
4. **进度记忆**：按书持久化阅读位置，重启 DSH、切换会话都能接着读。
5. **配置项**：书名、txt 路径、每块字数、插入间隔、总开关（Schemastery schema，cordis.yml 热更新）。

## 实施步骤

1. 调研 dsh-think-translate 源码，确认思维链流式渲染的拦截点与 UI 扩展 API（全项目唯一技术不确定点，先验证再动手）。
2. 搭 Cordis 插件骨架（TypeScript），用 `--patch` 本地加载跑通。
3. 写 txt 解析器：编码探测 + 切章 + 分块，配单元测试。
4. 接思维链流事件，实现块边界缓冲与插入逻辑。
5. 做卡片 UI + 进度存储 + 配置 schema。
6. 打包 bundle，`dsh plugin add` 安装实测，完善文档。

## 风险与对策

- DSH 处于开发者预览期，官方明示会有破坏性更新：锁定适配版本；UI 钩子失效时静默降级（不插小说，但绝不影响主界面）。
- 流式输出的块边界不一定对齐语义段落，需要缓冲策略，这是阅读体验的关键。
